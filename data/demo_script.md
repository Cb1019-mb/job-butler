# 3 分钟演示脚本

> 用于录屏求职管家"差异化能力"。配套 README §1 ~ §7 的故事线。
> 推荐录屏工具:**OBS Studio**(免费),输出 1080p 30fps。
> 浏览器:**Chrome / Edge** 全屏(F11),分辨率 1920×1080。

---

## 0:00 ~ 0:20 · 导入简历 + JD(20 秒)

**画面**:`http://localhost:8803/profile`

**操作**:
1. 鼠标聚焦"简历原文"textarea,粘贴提前准备好的简历文本(约 800 字)
2. 鼠标聚焦"目标 JD"textarea,粘贴目标岗位 JD(约 300 字)
3. **暂停 1 秒**让看的人看清字段标签
4. 点击"生成能力档案 →"按钮
5. 页面刷新,**滚动**到下方"当前档案"卡片

**镜头要点**:
- 镜头在"技能 / JD 重点 / 疑似短板"三排 pill 上**停 3 秒**(让看的人看清 4B 抽取的成果)

**画外音参考**(可选):
> "上传简历和目标 JD,4B 抽出结构化能力档案——技能、项目、JD 重点、疑似短板。"

---

## 0:20 ~ 0:50 · 发起模拟面试,答错暴露弱点(30 秒)

**画面**:点击顶 nav "模拟面试" → 进入 `/interview`

**操作**:
1. 岗位方向改为"AI 工程师"、公司填"字节"
2. 点"开始一场新面试 →"
3. 5 道题出来
4. **题 1(关于 Redis 持久化)** —— 在 textarea 里打一个**故意答错的短答案**:
   > "RDB 是定时备份,AOF 不太清楚。"
5. 点"提交并获取点评" → 等 ~5 秒,看三轴 JSON 流式出现
6. 鼠标**悬停在三轴评分上 2 秒**

**镜头要点**:
- 流式出现的 JSON 文本用 mono 字体,可读性高
- 截 1 张图存档("Redis AOF 答错" 的点评)

---

## 0:50 ~ 1:20 · 打开时间线,弱点已入库(30 秒)

**画面**:点击顶 nav "记忆时间线" → 进入 `/timeline`

**操作**:
1. 镜头扫过顶部 4 个状态计数卡片(ACTIVE / MASTERED / IDLE / DISABLED)
2. 镜头**停 5 秒**在第一张"Redis AOF 答错"记忆卡片上
3. 让看的人看清三件事:
   - 状态 tag 是 **ACTIVE**(黑底)
   - 强度条
   - 右下角"标记无效 / 标记已掌握"按钮
4. 镜头扫过整个记忆列表(可能还有其他自动沉淀的)

**画外音参考**:
> "答错后,系统从漏点里自动抽取弱点入库——来源可溯,可以标记无效,这是认知记忆的'产生'环节。"

---

## 1:20 ~ 1:50 · 第二场面试,出题明显针对弱点(30 秒)

**画面**:回 `/interview` 发起新会话

**操作**:
1. 点"开始一场新面试 →"(同岗位同公司)
2. **5 道题里 1~2 道是 Redis 题目**——镜头**在题目上停 3 秒**,让看的人能看出"这道题跟第一场是同一领域"
3. 这次**正常答**(显示你会用 AOF/RDB)
4. 提交,看三轴分提升

**镜头要点**:
- 重点展示 WEAKNESS 槽的两道题(题面 / category tag)
- 截 1 张图(对照"开/关记忆"的 WEAKNESS 槽差异)

**画外音参考**:
> "记忆开启后,出题器按 effective 排序从题库找命中题,主动针对答错过的知识点再训练。"

---

## 1:50 ~ 2:10 · MASTERED 状态转移(20 秒)

**画面**:回 `/timeline`,看 Redis AOF 那条记忆

**操作**:
1. 镜头停在第一张记忆卡
2. 演示:如果"再答对 1 次"会进 MASTERED——但单次演示做不到 2 次连续答对
3. **替代方案**:直接点"标记已掌握"按钮(模拟 MASTERED 状态)
4. 页面刷新,tag 从 `ACTIVE`(黑底)变成 `MASTERED`(边框)
5. 镜头**停 3 秒**在状态对比

**画外音参考**:
> "实际逻辑是连续答对 2 次自动转 MASTERED,出题权重骤降。这里手动模拟。"

---

## 2:10 ~ 2:40 · 看板 + 周报(30 秒)

**画面**:点击顶 nav "看板 + 周报" → 进入 `/kanban`

**操作**:
1. 镜头扫过 5 列看板(投递 / 笔试 / 面试 / offer / 挂),演示从下拉选"面试"→ 该卡片消失,出现在"面试"列
2. 滚到"成长周报"区域
3. 点"立即生成本周报告 →"
4. 弹出 Markdown,镜头停在 stats 数字上(场次 / 三轴平均分 / 仍薄弱 Top3)

**画外音参考**:
> "看板按阶段流转,周报每周日 23:59 APScheduler 自动生成,展示本周场次、三轴平均分、薄弱 Top3、下周建议。"

---

## 2:40 ~ 3:00 · MCP 工具调用 + 收尾(20 秒)

**画面**:`/api/mcp/memory/brief`

**操作**:
1. 切到浏览器新 tab,打开 `http://localhost:8803/api/mcp/memory/brief`
2. JSON 出现在屏幕上
3. 切回主 tab,镜头停在页面右上角品牌"求职管家"
4. 字幕 / 收尾一句话打出:
   > "它不是聊天记录,是一套会合并、会遗忘、能被验证的认知记忆。"

## 录屏设置建议

- **分辨率**:1920×1080
- **帧率**:30fps
- **编码**:x264,码率 8~10 Mbps
- **音频**:可选(不录就用字幕替代,避免环境噪音)
- **时长**:3 分钟以内(简历素材);5~6 分钟也可以(完整版)

---

## 不在演示脚本里的(自检)

- 主题切换:dark/warm 主题可在 settings 切换,演示在 `0:00` 前设置好
- timeline 强度条变化:在 timeline 页面停留够久,让看的人看出"宽度的意义"
- 简历文案:README §7 那段直接念一遍作为视频 description
